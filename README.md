# s21_decimal

**s21_decimal** - учебная библиотека на языке C для работы с точными десятичными числами.  

Проект посвящён реализации собственного типа `decimal`, которого нет в стандарте языка C, но который критически важен для финансовых расчётов, где недопустимы ошибки округления. Библиотека поддерживает арифметику, сравнение, преобразования и специальные операции над десятичными числами.

## Реализованные возможности

- поддержка арифметических операций: `add`, `sub`, `mul`, `div` с кодами ошибок;  
- операторы сравнения: `<`, `<=`, `>`, `>=`, `==`, `!=`;  
- преобразования типов: `int` ↔ `decimal`, `float` ↔ `decimal`;  
- специальные функции: `floor`, `round`, `truncate`, `negate`;  
- точное представление числа через битовый массив `bits[4]` (знак, 96-битное целое, коэффициент масштабирования);  
- поддержка диапазона значений от `-79,228,162,514,264,337,593,543,950,335` до `+79,228,162,514,264,337,593,543,950,335`;  
- соблюдение банковского округления при переполнении или ограничениях мантиссы;  
- префикс `s21_` для всех функций библиотеки;  
- покрытие unit-тестами через Check (≥ 80% функций);  
- сборка через Makefile с целями: `all`, `clean`, `test`, `s21_decimal.a`, `gcov_report`.
